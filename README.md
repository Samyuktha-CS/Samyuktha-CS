## Projects

### [Ghost in the Logs](https://github.com/Samyuktha-CS/ghost-in-the-logs): Privacy-First Local AI Security Log Analyzer

> Built for the **Hacktoberfest 2026** Week 4 DEV Challenge

A security log analyzer that runs **Llama 3.2 (1B) locally via Ollama** with a Python/Streamlit UI, so sensitive logs never reach third-party chatbots. Includes a SOC audit mode with threat severity rating, anomaly breakdown and remediation steps.

**Tools & Concepts:** Python · Streamlit · Ollama · Local LLMs · Log Analysis · Data Privacy

---

### [ComplianceGuard](https://github.com/Samyuktha-CS/ComplianceGuard): AI Security Gateway

> Designed during **Deloitte Digital Camp (China) 2026**

An AI-powered security compliance framework for corporate environments. It filters sensitive data from employee prompts before reaching AI tools (SensitiveShield), monitors AI-generated responses for harmful content (ResponseGuard), and logs all interactions into a periodic risk report (AuditBot).

**Tools & Concepts:** AI Gateway Design · Data Privacy · Regulatory Compliance · Enterprise Security

---

### [ResumeIQ](https://github.com/Samyuktha-CS/ResumeIQ): AI Resume Analyzer

> **2nd Prize, HackVerse 3.0** (AutoVerse category), St. Teresa's College

An automated resume screening pipeline built with Zapier. Collects candidate data via Google Forms, analyzes resumes using an AI module (ATS scoring, skill gap analysis), logs results to Google Sheets, and delivers personalized feedback via Gmail, fully automated.

**Tools & Concepts:** Zapier · Google Forms · Google Sheets · Gmail · AI Automation · ATS Optimization
